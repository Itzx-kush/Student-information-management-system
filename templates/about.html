System Architecture

This application consolidates three Week-8 practical questions into a single cohesive Flask web application:

  • Question A (Module A & C): Student Information Management System CRUD and Git Branch Management (branch creation, checkout, merging, and safe deletion).
  • Question B (Module A & D): Student Information Management System with the standard Git & GitHub remote workflow (clone, status, add, commit, push, pull).
  • Question C (Module B & E): Online Student Course Registration System with atomic seat decrement/restore and collaborative Git workflows (team feature branches, pull requests, merge conflict resolution).

Local Windows Execution

# 1. Clone repository git clone https://github.com/Itzx-kush/Student-information-management-system.git cd Student-information-management-system # 2. Create and activate virtual environment python -m venv venv venv\Scripts\activate # 3. Install dependencies pip install -r requirements.txt # 4. Start Flask application python app.py # Access in browser at: http://127.0.0.1:5000 # To stop the server: Press Ctrl + C in the terminal window

Relational Database Architecture (SQLite)

Table Name Primary Key Unique Constraints Description
students id roll_number, email Stores student academic profiles, contact details, and department allocation.
courses id course_code Defines academic course catalog, credits, instructors, and seat capacity.
course_registrations id (student_id, course_id) Tracks student enrollments, statuses (Active/Cancelled), and timestamps.

Security & Integrity

CSRF Security: All state-changing POST requests require a valid cryptographic CSRF token in session.

No Shell Execution: Git subprocess calls utilize shell=False with strict argument lists to prevent command injection.

Branch Protection: Deletion of the primary main or master branch is hard-blocked.

Atomic Transactions: Course registration and seat adjustments are executed inside atomic SQLite transactions.
