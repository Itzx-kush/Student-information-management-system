Practical Question A

Student Information Management System with Git Branch Management

Open Student CRUD Open Branch Lab
Aim To develop a Student Information Management System using Flask, HTML5, and SQLite, and demonstrate essential Git branch management operations including branch creation, switching, listing, merging, and branch deletion.
Software Requirements Operating System: Windows 10/11 • Language: Python 3.10+ • Web Framework: Flask 3.1 • Database: SQLite3 • Version Control: Git 2.40+

Algorithm / Procedure:

  1. Initialize Virtual Environment & Dependencies: Set up a local Python virtual environment (python -m venv venv) and install required libraries (Flask, Flask-SQLAlchemy).
  2. Implement Student Data Model: Define the Student schema in models.py with fields: id, name, roll_number (unique), email (unique), phone, department, year_of_study, semester, gender, address, and admission_date.
  3. Develop CRUD Routes: Implement routes for creating (/students/add), reading/filtering (/students), updating (/students/<id>/edit), and deleting (/students/<id>/delete) student records.
  4. Create Feature Branch: In the terminal, create an isolated feature branch:
    git branch feature-student
  5. Switch to Feature Branch: Check out the branch:
    git switch feature-student
  6. Develop and Commit Code: Implement student CRUD templates, stage changes with git add ., and commit with git commit -m "Implement student CRUD features".
  7. Switch Back to Main Branch:
    git switch main
  8. Merge Feature Branch: Integrate the student management feature into main:
    git merge feature-student
  9. Delete Merged Branch: Clean up the local branch pointer:
    git branch -d feature-student

Sample Terminal Output:

$ git branch feature-student $ git switch feature-student Switched to branch 'feature-student' $ git status On branch feature-student Changes to be committed: modified: models.py new file: routes/students.py $ git commit -m "Implement complete student CRUD operations" [feature-student c3d4e5f] Implement complete student CRUD operations 3 files changed, 210 insertions(+) $ git switch main Switched to branch 'main' $ git merge feature-student Updating 3440577..c3d4e5f Fast-forward models.py | 65 ++++++++++++++++++++++ routes/students.py | 145 ++++++++++++++++++++++++++++++++++++++++++++++ 2 files changed, 210 insertions(+) $ git branch -d feature-student Deleted branch feature-student (was c3d4e5f).
Result: The Student Information Management System was successfully implemented in Flask with full CRUD operations and persistent SQLite storage. Git branch creation, switching, merging, and safe deletion were verified without regression on the main branch.

Student Information Management System with Git and GitHub Workflow

Open Student CRUD Open GitHub Tutorial
Aim To develop a basic Student Information Management System using Flask and demonstrate the complete Git and GitHub remote workflow: remote repository creation, cloning, file modification, staging, committing, remote configuration, and pushing/pulling updates.
Repository URL https://github.com/Itzx-kush/Student-information-management-system.git

Procedure:

  1. Clone Remote Repository: Clone the central GitHub repository to the local machine:
    git clone https://github.com/Itzx-kush/Student-information-management-system.git
  2. Add Application Files: Create the Flask application files, directory structure, templates, CSS, and models.
  3. Verify Repository Status: Run git status to detect untracked and modified files.
  4. Stage Changes: Stage all files for the upcoming commit snapshot:
    git add .
  5. Commit Changes: Save snapshot with a descriptive commit message:
    git commit -m "Add student management system"
  6. Inspect Remotes: Verify configured remotes:
    git remote -v
  7. Push to Remote Main: Publish commits to the GitHub repository:
    git push -u origin main
  8. Pull Remote Changes: Retrieve upstream team updates:
    git pull origin main

Practical Question C

Online Student Course Registration System with Complete Git Workflow

Open Course Catalog Open Collaboration Lab
Aim To develop an Online Student Course Registration System using Flask with atomic seat capacity management, and demonstrate the complete collaborative Git workflow: repository initialization, file tracking, staging, commits, feature branching, merging, remote management, pull request reviews, and team integration.
Key Features Course catalog, seat decrementation upon registration, seat restoration upon cancellation, duplicate enrollment prevention, multi-developer branch simulation, and merge conflict resolution.

Procedure:

  1. Define Course & Registration Models: Implement Course (code, name, department, credits, max_seats, available_seats, instructor) and CourseRegistration (student_id, course_id, status, registration_date) with foreign key relationships and unique constraints.
  2. Implement Transactional Enrollment Logic:
    • Verify student and course existence.
    • Verify student is not already actively registered in the selected course.
    • Verify available_seats > 0; reject registration if zero.
    • Atomically create CourseRegistration and decrement course.available_seats -= 1.
    • Upon cancellation, set status to Cancelled and increment course.available_seats += 1.
  3. Collaborative Branching Strategy (Developer 1 & Developer 2):
    • Developer 1: Branches feature-student-management, commits student CRUD, and pushes branch.
    • Developer 2: Branches feature-course-registration, commits course registration logic, and pushes branch.
    • Team Lead: Reviews GitHub Pull Requests, tests code, resolves merge conflicts if any, and merges both feature branches into main.
  4. Pull Request Lifecycle: Create a pull request targeting main with comprehensive release notes, automated test results, and peer review verification.

Integration Commands:

$ git switch -c feature-course-registration $ git add . $ git commit -m "Implement Online Course Registration with transactional seat counters" $ git push -u origin feature-course-registration $ git switch main $ git pull origin main $ git merge feature-course-registration $ git push origin main
Result: The Online Student Course Registration System was developed with strict transactional integrity and capacity rules. The end-to-end Git collaboration lifecycle—incorporating feature branching, staging, atomic commits, pull request submission, and conflict resolution—was successfully demonstrated.
