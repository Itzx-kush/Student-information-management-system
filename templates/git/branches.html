Educational Concepts & Command Reference (Question A)

What is a Git Repository?

A Git repository is a digital storage space containing your project's complete history, snapshots (commits), references, branches, and configuration files managed under the hidden .git folder.

What is a Branch & Why Use It?

A branch is a lightweight movable pointer to a specific commit. Branches isolate experimental features or bug fixes from the stable main branch, allowing parallel work without risking production stability.

What is Merging?

Merging incorporates changes from one branch into another (e.g., merging feature-student into main). Git automatically combines non-conflicting edits via fast-forward or three-way merge commits.

Safe Branch Deletion

After a feature is merged, its branch pointer should be cleaned up using git branch -d <branch>. The -d flag safely checks whether all commits have been integrated before deleting.
